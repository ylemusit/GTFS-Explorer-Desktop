# GTFS Explorer 0.2.0 — Windows acceptance build

Estado técnico: `GTFS_EXPLORER_0_2_0_STATUS = ACCEPTANCE_BUILD_READY`  
Distribución: local, no publicada ni firmada.

La identidad numérica del ejecutable permanece en `0.1.0` porque la release
estable y su versión están congeladas durante el ciclo 0.2.0. `P2A-20260903-editor`
identifica el acceptance build del ciclo; no modifica `v0.1.0` ni sus artefactos.

## Toolchain recuperado

```ini
NSIS_VERSION = 3.12
MAKENSIS_PATH = C:\Program Files (x86)\NSIS\makensis.exe
INSTALL_SOURCE = EXISTING_LOCAL_INSTALLATION
REPRODUCIBILITY_GAP = NONE
```

La versión 3.12 está declarada en la documentación de packaging del proyecto.
`makensis` no estaba en `PATH`; se usó su ruta explícita únicamente para esta
sesión. No se instaló ni actualizó ninguna dependencia.
