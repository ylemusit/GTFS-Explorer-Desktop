# Decisiones del proyecto

Este documento registra únicamente decisiones relevantes que deban conservarse para evitar rediscutirlas o revertirlas por error.

No lo utilices como historial completo de cambios.

## Formato de decisión

### DEC-001 — Título de la decisión

Fecha: AAAA-MM-DD  
Estado: Aceptada

#### Contexto

Describe brevemente qué problema, restricción o necesidad llevó a tomar esta decisión.

#### Decisión

Indica claramente qué se decidió.

#### Motivo

Explica por qué se eligió esta opción frente a las alternativas relevantes.

#### Consecuencias

- Consecuencia positiva.
- Restricción o compromiso asumido.
- Impacto futuro importante, si existe.

#### No cambiar salvo que

Describe qué condición justificaría revisar esta decisión.
